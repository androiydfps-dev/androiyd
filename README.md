## Live

Repo: https://github.com/androiydfps-dev/androiyd

Domain bought: **androiyd.ai**

1. Enable GitHub Pages: Settings → Pages → Deploy from branch `main` / `/ (root)`
2. Pages custom domain: `androiyd.ai`
3. At the registrar, add:
   - `CNAME` `@` or `www` → `androiydfps-dev.github.io`
   - Or A records GitHub publishes for apex domains
4. Keep the `CNAME` file in this repo (`androiyd.ai`)

Temporary URL before DNS finishes: https://androiydfps-dev.github.io/androiyd/

## Files that must be in the repo root
